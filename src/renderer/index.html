设计灵感

本播放器的用户界面 (UI) 设计语言主要灵感来源于 Spotify 桌面客户端，旨在致敬其现代化、美观且用户友好的交互体验。

使用技巧

沉浸模式：双击播放区域（封面或视频）可进入或退出全屏沉浸式视图。

快进/快退：短按方向键 ← / → 可进行步进跳转，长按则可以倍速播放。

数据源致谢

本项目部分在线音乐搜索与播放功能基于 Meting 与 GD音乐台 (music.gdstudio.xyz) 提供的 API 实现。
