启用本地代理功能

首次使用需一次性完成以下配置，后续启动代理即可。

风险提示：本功能通过模拟浏览器行为或代理网络请求进行数据抓取，存在一定风险，且可能因目标网站更新而失效。请仅将其用于学习和技术演示，切勿用于任何商业用途。
1

安装 Node.js 环境

本地下载代理依赖 Node.js 运行时。如果您的计算机尚未安装，请从官方网站下载并安装 **LTS (长期支持)** 版本。

前往 Node.js 官网 请遵循标准安装流程，保留默认选项即可。
2

下载并解压项目文件

下载代理程序 (`agent.js`) 包含在本项目中。

下载项目 ZIP 压缩包 将解压后的文件夹放置在您方便访问的位置，例如“我的文档”。
3

安装依赖项与浏览器

打开您系统的 **终端** (Windows 上是 Command Prompt 或 PowerShell, macOS 上是 Terminal)。使用 `cd` 命令进入您刚刚解压的项目文件夹中的 `download/Player` 目录，然后运行以下命令：

npm install
此命令会安装所有依赖。注意：Playwright 会自动下载一个浏览器内核（约几百MB），请耐心等待。如果自动下载失败或卡住，请在此命令完成后，手动运行 npx playwright install 来安装浏览器。
4

启动下载代理

待依赖项安装完成后，在**同一个终端窗口**中运行以下命令以启动代理：

node agent.js
看到 "listening..." 字样即表示成功。**在使用功能期间，请勿关闭此终端窗口。**
